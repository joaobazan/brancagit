# brancagit

Primeiramente, abri o Windows Terminal e comecei criando uma pasta chamada atividade-git. Em seguida, entrei nela e criei o arquivo readme.txt. Depois, configurei meu nome como João Paulo e meu e-mail como bozajoaopaulo@gmail.com para identificar meus commits no Git.

Após fazer a configuração, iniciei o Git com o comando git init e escrevi no arquivo a frase "Atividade de Git realizada por João Paulo". Depois, adicionei o arquivo ao Git usando git add readme.txt e realizei meu primeiro commit com a mensagem "Primeiro commit".

Por fim, para adicionar novos arquivos ou modificações, utilizei os comandos git add . e git commit -m "Primeiro commit: criando e modificando arquivo". Assim, concluí a atividade, aprendendo a criar arquivos, configurar o Git e registrar alterações por meio de commits.
